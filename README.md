This bot is a recycling / environmental knowledge bot in the style of Ivern from League of Legends.

There are fixed item names and several commands which gets the user general knowledge about how to properly recycle items, learn benefits and results for recycling a specific item

commands:

$_commands
$get_help
$how_to_recycle
$benefit
$result

Items:

Glass
Paper
Aluminum
Plastic
Batteries
Concrete
Organic_waste
Electronic_waste
Iron
Textiles
